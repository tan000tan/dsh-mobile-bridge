# 故障排查文档（阶段 D）

现象 → 原因 → 处置。按用户实际使用顺序排列。

## 一、连接类

| 现象 | 可能原因 | 处置 |
|---|---|---|
| 连接页提示 Refused（主动拒绝） | 电脑可达但桥接未运行/端口错 | 启动托盘或 `node bridge.js`；核对桥接端口与手机填写端口一致 |
| 提示 Timeout | 不同网段/防火墙丢包 | 确认手机与电脑同网（或经 Tailscale）；桥接 listenHost 是否改成了电脑内网 IP |
| 提示 401 Unauthenticated | DSH 凭据过期（DSH 重启换了 launch token） | 电脑端复制新启动 URL 的 token，手机重新连接（DSH 每次重启换 token 是官方设计） |
| 提示 401（桥接层 unauthorized） | 设备令牌被撤销/轮换或填错 | PC 上 `node bridge.js devices list` 核对；需要时 `devices add` 重新发放 |
| 提示 429 | 认证失败过多触发临时封禁（10次/分钟→封5分钟） | 等待自动解除；核对手机端令牌是否正确 |
| 显示 UPSTREAM_DOWN / "DSH未启动" | 桥接在线但 DSH web 未启动 | 手动 `dsh web`（本项目绝不自动启动 DSH） |
| 信任栅栏 403 | Host 栈栏拒绝 | 确认未绕过桥接直连 DSH；桥接会自动重写 Host，直连场景需 DSH 的 --trusted-host（属 DSH 配置变更，须批准） |

## 二、运行类

| 现象 | 可能原因 | 处置 |
|---|---|---|
| 手机有网络但桥接状态页 dsh=not_running | DSH web 停止/换端口 | 启动 DSH；核对 桥接配置.json 的 dshPort |
| 通知不出现 | 通知权限未授予/会话正在前台 | 系统设置授予权限；前台会话按设计抑制通知（用户正看着） |
| 收不到"任务开始"通知 | 设置中已关闭 | 设置→通知→任务开始时通知 |
| 审批卡自己消失 | DSH 侧已结算（电脑端已批准/拒绝/超时）——审批是主机内存态 | 属官方语义；电脑端查看 approval/decided 审计 |
| 离线快照不更新 | 快照仅在成功刷新会话列表后落盘 | 重连成功后自动更新；这是"只读缓存"设计 |
| 桥接日志有 AUTH_FAIL | 错误令牌探测/旧令牌 | 关注是否持续出现；持续=有设备用失效令牌，必要时 rotate |
| 手机连接正常但看不到某个 0.2.x 功能 | 0.1.7-rc.2 无该能力（capability 404） | 预期行为：客户端自动隐藏不支持的能力；升级 DSH 属手动决策 |

## 三、桥接管理

| 操作 | 命令（电脑本机执行） |
|---|---|
| 查看设备 | `node bridge.js devices list` |
| 新增设备 | `node bridge.js devices add <名称>`（明文令牌只显示一次） |
| 撤销设备 | `node bridge.js devices revoke <id>`（即刻失效） |
| 轮换令牌 | `node bridge.js devices rotate <id>`（旧令牌即刻失效） |
| 查看审计 | `电脑端桥接服务源码\dsh-bridge\审计日志\audit-*.jsonl`（JSONL，已脱敏） |
| TLS 证书 | 运行 `建立TLS证书.ps1` 后按打印说明配置（配置后仅 HTTPS，禁降级） |

## 四、构建类

| 现象 | 处置 |
|---|---|
| SDK location not found | 核对 fork 的 local.properties 指向项目内 AndroidSdk（properties 中冒号写 `D\:`） |
| non-ASCII path 拒绝构建 | 确认 gradle.properties 有 `android.overridePathCheck=true` |
| 测试全类 ClassNotFoundException（中文路径） | JDK17 启动器 @argfile 编码限制——用联接路径跑 Gradle 测试，或用无联接直跑方案（导出classpath+JDK25 JUnitCore，工具在 自动化测试与测试结果\） |
| lint 报 MissingTranslation | 新增字符串必须补齐 12 语言（脚本模式见 临时文件与构建缓存\补写字符串*.js） |
| gradle 依赖下载失败 | github 需经本机代理 127.0.0.1:7890；maven/google 直连即可 |
