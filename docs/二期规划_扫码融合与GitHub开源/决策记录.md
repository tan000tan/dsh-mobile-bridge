## public 可见性的连带要求（升级为硬性闸门）

用户选 public，S7 脱敏清单从"建议"升级为**强制核销**，任何一项未过不得推送：

1. 五个一次性/令牌文件（设备令牌_一次性.txt、设备发放输出_一次性.txt、启动URL_一次性.txt、e2e运行/令牌记录.txt）绝不进库；
2. devices.json 绝不进库；
3. 全库 grep 扫 `172.18.`、`dsh-auth-`、64 位 hex、`token=`，命中逐处人工裁决；
4. 含内网 IP/个人验收时间线的文档（最终验收报告、真实环境验收执行记录、92项需求原文.txt 等）**不进公开库**或脱敏后进；
5. APK 只走 GitHub Releases，不进 git 树；
6. 推送前仍需用户一句"确认推送"（对外发布动作，明示授权留痕）。
