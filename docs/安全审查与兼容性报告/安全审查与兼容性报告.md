# 安全审查与兼容性报告（阶段7）

审查时间：2026-10-24。方法：源码审读 + 自动化测试佐证 + 只读环境核对。每项结论标注【已验证】【未验证】或【需授权】。

## 一、逐项安全检查

| # | 检查项 | 结论 | 依据 |
|---|---|---|---|
| 1 | 硬编码密钥 | ✅ 无【已验证】 | 全部源码 grep 无密钥/令牌字面值；桥接令牌首次运行由 CSPRNG 自动生成进本机配置；E2E 配置中的令牌为一次性本机测试值（目标为已停止的本地 mock），且在项目目录内 |
| 2 | 不必要的网络暴露 | ✅ 默认仅回环【已验证】 | bridge.js 默认 listenHost=127.0.0.1（测试13验证非回环必须显式配置）；绑定非回环时启动横幅强制警告；无任何公网组件、无中继、无 DSH 端口暴露（0.1.7-rc.2 官方亦拒绝 0.0.0.0） |
| 3 | 越权访问路径 | ✅ 由 DSH 自身栅栏承担【已验证】 | 手机不获得任何文件系统旁路：文件浏览/读取走 DSH 原生 workspaceFiles API（DSH 自己的工作区边界）；桥接仅透明转发，不解析不改写业务路径；DSH 的 Host/Origin 栅栏保持原样（桥接只重写 Host 为真实目标地址，不伪造 Origin） |
| 4 | 上传文件误执行 | ✅【已验证（机制层）】 | 上传走 DSH 原生 session/attachment 流程，进入 DSH 附件管理，不触发执行；桥接不执行任何内容；本项目未新增任何上传入口 |
| 5 | 重连后自动提交草稿 | ✅ 无【已验证】 | 草稿仅本地文本，发送永远需要用户显式点击；离线快照（本次新增）为只读展示、不参与发送（OfflineSessionSnapshot 测试佐证只读性）；重连逻辑为上游 P1 原生（重建连接而非重放消息） |
| 6 | 事件重复处理 | ✅ 有去重【已验证】 | 通知层 dedupKey 去重（会话id+seq/事件id，容量1024环形）；SessionStarted 以"每轮运行一次"状态机去重（5项单测覆盖）；下游消息按上游 seq 语义处理 |
| 7 | 并发写入冲突 | ✅ 由 DSH 会话单写入者锁承担【已验证（机制层）】 | 官方文档确认每会话一个活写入者（内核锁，occupied sessions reject）；桥接只读转发不产生第二写入者；本机 ~/.dsh/task-board 等非官方文件未依赖 |
| 8 | 审批是否真正约束执行 | ✅ 机制真实【已验证（机制层）/ 真机【需授权】】 | 审批应答经 `$events/result` 回到 DSH 进程内 approval 缝（与桌面浏览器同通道）；DSH 无 answerer 时 fail-closed（官方文档）；手机端弹窗明确标注为咨询（RiskAdvisory 注释与字符串文案均声明"电脑端审批才是真正的执行边界"） |
| 9 | 暂停/取消状态真实性 | ✅【已验证（机制层）】 | 全部状态来自 DSH 真实应答（session/cancel、goal.pause/resume、api-session/status）；桥接 DSH 停止时如实 502/状态接口 not_running（测试8/9），无伪造 |
| 10 | 日志脱敏 | ✅【已验证】 | 桥接测试12：任何日志不含令牌/查询串；桥接不记录请求体；手机端不打印 URL 到持久日志 |
| 11 | 令牌存储 | ✅ 设计符合上游教训【已验证】 | 桥接令牌仅存本机配置文件（用户自管）；DSH launch token 每次启动轮换、应用不持久化过期凭据（P1/P2 一致结论）；桥接令牌经 URL 路径传递（应用无自定义头能力下的最短方案），已记录 P4 的"走自定义头更优"备选改进 |
| 12 | 传输加密 | ⚠️ 明文 HTTP（局域网）【如实声明】 | 与 P1 直连模式同等；缓解：默认回环+令牌 fail-closed+建议 Tailscale/WireGuard 承载（文档化，未默认配置）；公网使用被架构性排除 |
| 13 | 重放攻击 | ✅ 由上游协议承担【已验证（机制层）】 | DSH cookie 绑定 authority、WS 客户端 id 代际校验（P1 ConnectionLoop）；桥接无状态不引入新重放面 |
| 14 | 会话失效 | ✅【已验证】 | DSH 重启=新 launch token（旧凭据自然失效）；桥接重启=新令牌（用户重新粘贴）；应用 401 回设置页 |

- **DSH 本体/配置/插件：零修改**（本机 `dsh --version` 全程未变；~/.dsh 仅只读）。
- DSH 未被启动/停止（模拟器实测用的是 P1 的 mock-harness，非真实 DSH）。

- 本次扩散的外部产物（3 个联接+1 个 AVD）已全部安全移除；~/.gradle 共享缓存新增条目保留并记录原因。
