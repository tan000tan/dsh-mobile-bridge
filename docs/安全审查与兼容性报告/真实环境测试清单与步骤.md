# 真实环境测试清单与步骤（阶段 C · 待用户授权后执行）

前置阅读：《真实环境验证准备与授权清单.md》《合并授权清单.md》《真实DSH兼容性验证报告.md》。
任务纪律：全部测试使用**安全、可取消、无破坏性**任务（见第三节任务白名单）；未经授权不执行删除/覆盖/批量/不可逆操作。

## 一、环境准备（一次性，约 5 分钟，全部由你亲手执行）

| 步 | 操作 | 预期 |
|---|---|---|
| P1 | 手动执行 `dsh web`（保持默认 127.0.0.1:3080） | 启动输出含 `http://127.0.0.1:3080/?token=<本次launch token>` |
| P2 | 记录本次 launch token（仅粘贴用，不存档） | — |
| P3 | `电脑端桥接服务源码\dsh-bridge\启动托盘.bat`（或命令行 node bridge.js） | 托盘显示"运行中"；`node bridge.js devices list` 至少一台活跃设备 |
| P4 | 若无活跃设备：`node bridge.js devices add 手机` | 打印一次性设备令牌与地址 `http://<电脑IP>:3090/<设备令牌>` |
| P5 | 手机安装 `构建产物与安装包\DSH手机控制台_v0.18.0-r5_阶段五.apk`（先核对 SHA-256） | 安装成功 |
| P6 | 手机与电脑同一网络（或按合并授权清单先行实施 Tailscale） | 手机浏览器能打开 `http://<电脑IP>:3090/`（无令牌应 401——即 fail-closed 生效） |

失败处理：P3 失败→查桥接配置 json 语法；P6 打不开→核对 listenHost 是否已改为电脑内网 IP 且重启桥接（见合并授权清单第 1 项）。

## 二、七项验证点（每项：步骤/预期/失败处理/回滚）

### V1 手机与桥接服务认证
- 步骤：手机 App 连接页填 P4 地址 → Connect。
- 预期：进入聊天主界面；设置页显示连接信息；无令牌或错令牌的替代输入会得到 401 提示。
- 失败处理：401（桥接）→ 核对设备令牌/`devices list`；401（DSH）→ launch token 过期，取 P1 新 token 重连（DSH 每次重启换 token 属官方设计）。
- 回滚：App 设置里删除该主机即可。

### V2 手机发送请求并到达真实 DSH
- 步骤：新建会话 → 发送白名单任务（第三节）→ 观察流式输出。
- 预期：输出逐段实时出现，与电脑端 DSH 界面内容一致；轨迹页有逐轮事件与时间。
- 失败处理：红色能力横幅=该功能 0.1.7-rc.2 不支持（如实显示，非故障）；无输出→核对电脑端 DSH 是否正在执行。
- 回滚：无（只读观察+一条会话消息）。

### V3 任务状态、事件流、输出及错误信息来自真实 DSH
- 步骤：在 V2 会话中发送一条会失败的任务（如"读取一个不存在的文件名"），观察错误呈现。
- 预期：错误信息为 DSH 原文；轨迹含失败轮；不出现编造的阶段或摘要。
- 失败处理：与电脑端显示不一致→截图登记（兼容性缺陷）。
- 回滚：无。

### V4 审批：允许 / 拒绝 / 过期 / 重复 / 断线
- 步骤：发一条会触发 DSH 审批的任务（例如要求 DSH 在工作区创建并运行一个临时脚本——具体触发以 DSH 实际审批策略为准）；在手机批准卡上分别测试：批准；下一轮再触发并拒绝；批准后 3 秒内快速再点一次（应无效）；批准前断开手机网络 10 秒再恢复。
- 预期：批准→DSH 真实执行该步；拒绝→该步被挡；重复点击无第二次效果；断线恢复后状态如实（卡消失或显示主机已结算），绝不自动重发。
- 失败处理：批准后 DSH 未执行→立即在电脑端终止该会话并登记（严重缺陷）。
- 回滚：被批准的操作限于白名单任务范围内；会话可在 DSH 端删除。

### V5 设备撤销、会话过期及重新配对
- 步骤：a) PC 执行 `node bridge.js devices add 备用机` 与 `revoke <主设备id>`；b) 手机继续操作；c) `devices rotate` 后按打印的新令牌重新配对。
- 预期：a 后手机即刻 401（撤销即刻失效——已在模拟端到端实证）；c 旧令牌失效、新令牌可连。
- 失败处理：未生效→登记（撤销语义缺陷）。
- 回滚：`devices add` 重新发放即可。

### V6 文件预览和下载的授权边界
- 步骤：Workspace 面板浏览 DSH 工作区 → 预览一个文本/图片/HTML 文件 → 下载一个文件（SAF 选择位置）。
- 预期：仅见 DSH 工作区内容；HTML 预览无脚本执行；下载落点为你选择的位置。
- 失败处理：出现工作区外内容→立即登记（越权缺陷）。
- 回滚：无（只读操作）。

### V7 网络中断后的恢复及未知状态处理
- 步骤：任务运行中关闭手机 Wi-Fi 10 秒 → 恢复；再关闭电脑侧桥接 30 秒 → 重启桥接。
- 预期：手机显示断线与恢复过程；恢复后状态来自 DSH 真实应答；运行中任务在 DSH 侧不受影响继续执行；无自动重发。
- 失败处理：恢复后出现重复事件→登记（去重缺陷）。
- 回滚：无。

## 三、测试任务白名单（仅允许这些）

1. "回复 pong"类的纯文本对话任务。
2. 在 DSH 工作区内创建/读取一个临时文本文件（名字带 test- 前缀），结束时由你在电脑端删除。
3. 触发审批的任务以上述第 2 项为基础（DSH 审批策略自然触发，不人为加码）。
**禁止**：删除/覆盖既有文件、批量操作、安装卸载、网络配置、任何不可逆动作。
