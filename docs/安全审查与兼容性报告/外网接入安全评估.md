# 外网接入安全评估（阶段 C · 方案文档，实施需授权）

时间：2026-10-24。需求基线：#2（手机流量/校园网/其他 Wi-Fi 可访问）、#16（优先免费、安全、开源；不付费 relay；不直曝公网）、#21（方案先行、实施先批）、#29（加密传输/身份验证/设备绑定/禁降级）、安全底线 4（不暴露 DSH；配对凭据强随机可撤销）。

## 候选方案对比

| 方案 | 成本 | 加密/身份 | 评估 |
|---|---|---|---|
| **Tailscale（WireGuard mesh）** | 免费档（个人 3 用户/100 设备）开源客户端 | WireGuard 端到端加密；tailnet 内身份=设备密钥；可开 ACL | ✅ **推荐**：满足 #16 全部偏好；`tailscale serve` 可把桥接仅发布到 tailnet（零公网暴露面）；与桥接令牌叠加（网络可达≠授权，双层） |
| 自建 VPS 中继 | 服务器+域名费用 | 需自建 TLS/认证 | ❌ 违背"不付费优先"，运维负担 |
| 端口映射/DMZ 到公网 | 免费 | 无 | ❌ 安全底线明确禁止 |
| Cloudflare Tunnel | 免费 | CF 终结 TLS（第三方可解密风险，DSH-Remote 评审已否决该类承载 RCE 级凭据） | ❌ 与 #29"服务器身份验证/设备绑定"取向不符 |

## 推荐部署形态（授权后实施）

1. **PC 安装 Tailscale 并登录**（你操作：系统安装+账户授权——均属需批准项）。
2. **桥接保持默认回环**；以 `tailscale serve --bg --https=443 http://127.0.0.1:3090` 把桥接发布到 tailnet（仅 tailnet 成员可达，证书自动）。脚本要点：发布前校验 serve 后端必须指向回环（拒绝误配公网后端），参照 DSH-Remote 的脚本纪律。
3. **手机安装 Tailscale 并登录同一 tailnet**；主机地址填 `https://<机器名>.<tailnet>.ts.net/<设备令牌>`。
4. **安全层叠加**：WireGuard（传输）+ 桥接设备令牌（授权，可撤销/轮换）+ DSH 自身凭据（最内层）。三层各自失效互不替代。
5. **禁止降级**：公网场景一律 `https://`（tailscale serve 自动 TLS）；桥接如另配自签 TLS（建立TLS证书.ps1）则仅 HTTPS 监听。

## 风险与边界（如实）

- Tailscale 协调服务器可见元数据（设备名/在线状态），不可读流量内容（WireGuard 端到端）。
- tailnet 成员资格=可达性，**令牌才是授权**（既有测试佐证：无/错/撤销令牌一律 401/429）。
- 明文 LAN 模式风险独立存在（见网络审计报告第二节）；跨网场景一律不再使用明文。
- 本评估**未执行任何安装/网络变更**；实施步骤见《真实环境验证准备与授权清单》。
